# Tip Split

A one-page bill splitter: the bill, a tip, how many people, and what each
person pays. Plain HTML and JavaScript, nothing to install.

Open `index.html` in a browser, or serve it:

```sh
python3 -m http.server 8000
```

This repository is a sample for the factory manager: something small to file
an issue against and watch it get triaged, fixed and opened as a PR.
